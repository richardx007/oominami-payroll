# 解説動画のデザイン標準（縦・スマホ用）

2026-09-27 オーナー決定: **解説動画は縦（1080×1920）を標準**とする。管理者・従業員とも、アプリの解説はスマホで見ているため。
見本（基準の実装）は `movies/eigyo-calendar-tate/`。新しい動画・作り直しはこれを写して始める。
既存の横の動画4本は、2026-09-27〜28 にすべて縦版（`movies/<名前>-tate/`、出力名の末尾 `_縦`）に作り直した。
横の元（`movies/<名前>/`）は作り直しの元として残してある。

判断の目安は「**iPhone を縦に持ったまま、全画面にしなくても読めること**」。
1080px の画面は iPhone で約390pt 幅に縮むので、1px ≒ 0.36pt。説明の文字 38px ≒ 14pt、補足 28px ≒ 10pt。
**見出し以外の文字はできるだけ大きく**。1行に収まらないときは、小さくするより改行する（オーナー方針）。

## 1. 画面（キャンバス）

| 項目 | 値 |
|---|---|
| 大きさ | 1080×1920（`config.json` に `"size": [1080, 1920]`）・30fps |
| 左右の余白 | 60px（文字の幅は最大 960px） |
| 上の帯（説明の文字） | y 0〜約740。章ラベル・見出し・説明をここに収める |
| 下の帯（見せるもの） | y 約748〜1900。スマホの模型・ブラウザの画面など |
| 進み具合のバー | 下端 6px（青→緑のグラデーション） |

- スマホの模型は **1.2倍**（`B = 1.2`）。中心 `HOME = [540, 1324]`（下端に合わせる）。高さ 1152px。
- 拡大（カメラのズーム）は 1.2倍の上にかける（例: 日付セルを見せるとき `1.85 * B`）。拡大中は上の帯に重ならないよう、
  電話の上側を y 720〜840 でぼかして消す（マスク）。
- 横に並べていたもの（3枚のカード、アプリ→ホームページの矢印など）は**縦に積む**。矢印は下向き。
- 3つを横に比べたい図（運用例の10月・11月・12月など）は幅 310px ずつ・間隔 35px で横に並べてよい。

## 2. 文字の大きさ

| 用途 | 大きさ・太さ | 例 |
|---|---|---|
| オープニングの題名 | 130px / 900 | 営業カレンダー |
| 見出し（場面のタイトル） | 56px / 900、行間1.2、最大2行 | 「① 臨時休業にする」 |
| 章ラベル | 28px / 800、番号の四角 60px | 「04 いつもと違う日を直す」 |
| 説明（tip） | 38px / 600、行間1.45、アイコン 52px | 「日をタップ」「臨時休業 を選ぶ」 |
| 吹き出し（callout）本文／補足 | 36px / 700 ／ 28px、番号の丸 54px | 「右上のボタン／HPでの見え方…」 |
| 要点カード（point）本文／補足 | 40px / 800 ／ 29px | 「いつもの日／ルールどおりに…」 |
| 流れのカード | 時期 31px・本文 52px・説明 31px | 「毎月15日／翌々月分を自動で作成」 |
| 表（ルール表など） | 38px / 800 | 「月〜木　10:00〜23:00」 |
| 時点のラベル（見どころ） | **44px / 900**、青地に白 | 「10月15日」「10月末」「11月1日」 |
| まとめの手順 | 時期 32px・本文 38px | 「10月15日／12月分が自動で作られる」 |
| 状態のバッジ | 28〜30px / 900 | 公開中・準備中 |
| クレジット | 20px / 600、右下 | ナレーション　VOICEVOX:ずんだもん |

- **下限は補足で 25px**（それ未満は使わない）。ただし、スマホ・ブラウザの模型の中（実際の画面の再現）は実物の縮尺のまま。
- 長い文は、意味の切れ目で `<br>` を入れて改行する（例: 「12月がホームページに公開<br>（公開中は 11月・12月）」）。
  自動の折り返しで「12／月）」のように語の途中で切れないようにする。
- 見出しが2行になる場面では、続く要素の上端を 290px 前後にする（1行なら 250〜260px から）。

## 3. 色

| 名前 | 値 | 使いどころ |
|---|---|---|
| 背景 | `#f3f5fa` ＋ 点の格子・ぼかした色の円（青 `#bcd3ff`・緑 `#c8f0d8`・黄 `#ffe8a8`） | 全体 |
| 文字 | `#0f1b3d`（navy） | 見出し・本文 |
| 強調 | `#2563eb`（blue） | 見出しの強調語（`<em>`）、番号、時点のラベル、枠 |
| 補足の文字 | `#64748b` | small |
| 公開中・OK | `#16a34a`／薄 `#dcfce7` | |
| 準備中 | `#ca8a04`／薄 `#fef08a` | |
| 臨時休業・注意 | `#dc2626`／`#ef4444` | |
| 変更の目印・光 | `#f97316` | 手で変更した日 ●、変更箇所の光 |
| オープニング・場面転換の幕 | `#0f1b3d`〜`#1e3a8a` のグラデーション | |

アプリの模型は、実際の画面の色・文言に合わせる（アプリ側の Tailwind の色）。

## 4. 部品

- **カード類**（callout／point／node）: 白地・角丸 20〜24px・影 `0 14px 36px rgba(15,27,61,.10)`。
  縦に積むときは、point は `padding:16px 26px; line-height:1.25`（高さ約120px）にして間隔 145px 前後で並べる（詰めすぎると影が重なって1枚に見える）。
- **スマホの模型**: 458×960 の枠（角丸66px）＋ 430×932 の画面。ステータスバーは「9:41」など固定の時刻。
- **指**: 青い半透明の丸（46px）＋ 押した瞬間の波紋。タップは `FINGER` に [時刻, 対象, 1]。
- **強調の枠**: スマホ内の対象を青（または赤）の角丸枠で囲む。縦では吹き出しから線を引かない
  （吹き出しが上、スマホが下で線が交差するため）。代わりに**枠の右上に吹き出しと同じ番号の丸**を付ける。
- **時点のラベル**: 線の上を動く青い丸（36px）と、その下の青いラベル（44px）。画面端では左右 180〜900px に収める。
- **オープニング**: 紺の幕に「対象（管理者向け／従業員向け） 操作ガイド」→ 題名 → 章の札を縦に3つ → 「約 N 分」。
- **まとめ**: 場面の最後に要点を3〜4項目。右下にクレジット、下部に「オオミナミ　<題名>」。

## 5. 動き・音

- 要素の出入りは `data-a="出る秒,消える秒"` ＋ `data-fx="up|left|right|pop|fade"`（追加場面は `data-n`）。
- 場面の切り替えは、オープニングは上へワイプ、まとめは下からワイプ。
- ナレーションは VOICEVOX「ずんだもん（ノーマル）」。読みの直しは `dictionary.json`。文が区間に収まらなければ映像が伸びる。
- BGM は自作の合成音。ナレーション中は自動で下げ、全体 −16 LUFS。
- 🔴 VOICEVOX の利用規約により「**VOICEVOX:ずんだもん**」のクレジットを必ず入れる。

## 6. 横の動画から作り直すとき

場面が多く上の帯（〜740px）に収まらないときは、**時間で分ける**: 前の項目を消してから、同じ場所に次の項目を出す
（`data-a` の終了秒を、次の項目が出る直前にする）。横に並んでいた図は縦に組み替える
（例: 役割の図は左→右の線を上→下の木に、日付カード4枚は2×2＋境目の横線に、パソコンの画面は下の帯へ）。

1. `movies/<名前>` を `movies/<名前>-tate`（または置き換え）に写し、`config.json` に `size` と縦の出力名を書く。
2. ステージを 1080×1920 に、`svg#lines` も同じ大きさに。`getBoundingClientRect().width / 1920` の縮尺計算は `/ 1080` に。
3. `.h1/.tip/.callout/.point/.sub` を上の表の大きさに上書きし（`eigyo-calendar-tate/movie.html` の「縦用の上書き」をそのまま使える）、
   各要素の `top` を上の帯（〜740px）に収まるよう詰め直す。
4. カメラの `HOME`・`B`・ズームのマスクを上の値に。ブラウザの模型は下の帯（`left:30px; top:1040px`）。
5. `snap.mjs` で全場面を静止画で確認 → 文字が重ならないか・語の途中で折り返していないかを見る → `build.mjs`。
   ナレーションを変えていなければ `video mix light` だけでよい。
